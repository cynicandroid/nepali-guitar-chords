# Tabla samples

These WAV files are the original tabla bols recorded by mmiron and released
under the Creative Commons Zero (CC0) dedication on Freesound:

<https://freesound.org/people/mmiron/packs/8162/>

The application uses the files as individual strokes and combines them into
common Hindustani tabla bols such as Dha and Dhin. The source filenames were
renamed locally to remove Freesound's numeric/uploader prefix; the audio data
was not edited.
