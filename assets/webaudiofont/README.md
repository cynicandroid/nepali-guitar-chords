# WebAudioFont resources

These vendored files provide the sampled guitar strumming sound used by the
songbook:

- `WebAudioFontPlayer.js`
- `0250_SoundBlasterOld_sf2.js`

Source: [WebAudioFont](https://github.com/surikov/webaudiofont) and
[WebAudioFontData](https://github.com/surikov/webaudiofontdata)

The upstream project and soundfont data have their own license terms. See the
upstream repositories before redistributing these resources separately.
