# 🎶 Nepali Guitar Chords & Tabs Collection 🎸

Welcome to the **Nepali Guitar Chords & Tabs Collection**! This repository is an interactive, digital songbook containing chords and lyrics for over 200+ popular Nepali, Hindi, and English songs.

## 🌟 Features

- **Perfect Chord Alignment:** Every song is rendered using a monospaced layout to ensure that chord symbols remain perfectly aligned above the lyrics, matching the original formatting.
- **Seamless Sequential Navigation:** Every song includes handy `⏮️ Previous` and `⏭️ Next` links, allowing you to flip through the songbook sequentially like a real binder.
- **Instant Search & Transposition Web App:** Launch the companion static web app to search songs instantly, adjust font sizes, auto-scroll, and **transpose chords** on-the-fly to match your voice!

## 🖥️ Interactive Web Companion (GitHub Pages)

You can open `index.html` in any browser to launch the beautiful, responsive, mobile-friendly songbook web app. It is completely static and ready to be hosted on **GitHub Pages**!

### Web App Highlights:

- 🔍 **Instant Search:** Find any song by title in milliseconds.
- 🎼 **Transposition:** Transpose the key of any song up or down with a single click (with column alignment preserved!).
- 📜 **Auto-Scroll:** Play hands-free with adjustable scrolling speed.
- 🌓 **Dark Mode:** Easy on the eyes for late-night campfire jam sessions.
- 📏 **Font Adjuster:** Zoom in or out to fit your screen perfectly.
